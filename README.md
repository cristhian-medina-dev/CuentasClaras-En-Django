# CuentasClaras

Aplicación web desarrollada con **Django** para organizar eventos y dividir gastos compartidos de forma simple, transparente y ordenada.

## Funcionalidades actuales (MVP)

- **Autenticación de usuarios:** Inicio y cierre de sesión con rutas protegidas (`login_required`).
- **Gestión de eventos:** Creación de eventos asociados al usuario autenticado, visualización del historial ordenado del más reciente al más antiguo y eliminación segura mediante `POST`.
- **Interfaz responsiva:** Diseño limpio centralizado en CSS puro con barra de navegación fija.

## Tecnologías utilizadas

- **Backend:** Python 3.14, Django 6.1
- **Base de datos:** SQLite
- **Frontend:** HTML5, CSS3
